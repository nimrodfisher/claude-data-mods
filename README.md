# claude-data-mods

**Mods that make Claude Code smarter to work with.**

![Claude HUD demo](mods/level-up-hud/docs/demo.gif)

</div>

## Mods

| Mod | What it does |
| --- | --- |
| 🎮 [**level-up-hud**](mods/level-up-hud) | A live HUD beside the chat: usage limits, context, and a coach that spots wasted context in every session, with a one-click fix. You earn XP for real work and nothing for waste. |
| 🤖 [**agents-panel**](mods/agents-panel) | One panel listing every running Claude Code session: what needs you, what's running, what's done, with model, effort and tokens. |

## ⚡ Install

In Claude Code, run:

```
/plugin install level-up-hud --marketplace nimrodfisher/claude-data-mods
/plugin install agents-panel --marketplace nimrodfisher/claude-data-mods
```

Answer **`y`** to add the marketplace, pick the **user** scope, then restart Claude Code. Run **`/hud`** or **`/agents-panel`** to open a pane at any time.

More options, including updating and removing, are in the [level-up-hud README](mods/level-up-hud#-install).
