# claude-data-mods

Mods for Claude Code.

| Mod | What it does |
| --- | --- |
| [level-up-hud](mods/level-up-hud) | Gamified HUD pane + status line: model, effort, 5-hour and weekly usage limits with reset countdowns, context, cost, XP/levels and a daily quest. |

## Install

In Claude Code:

```
/plugin install level-up-hud --marketplace nimrodfisher/claude-data-mods
```

Answer `y` to add the marketplace, then choose **user** scope.
